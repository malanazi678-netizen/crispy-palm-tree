# مهارات التسويق للسوق السعودي — Saudi Marketing Skills for Claude

حزمة مهارات (Claude Code Skills) متخصصة في التسويق داخل المملكة العربية السعودية. كل مهارة ملف `SKILL.md` داخل `.claude/skills/` ويستدعيها Claude تلقائياً عندما يكون طلبك متعلقاً بها، أو تستدعيها بالاسم مثل `/saudi-campaign-planner`.

| المهارة | ماذا تفعل |
|---|---|
| `saudi-campaign-planner` | **ابدأ هنا** — خطة حملة كاملة تجمع باقي المهارات |
| `saudi-market-research` | دراسة السوق، الشرائح، المناطق، المنافسين، رؤية 2030 |
| `saudi-arabic-copywriting` | كتابة إعلانات بالسعودي الأبيض / النجدي / الحجازي / الفصحى |
| `saudi-social-media` | سناب، تيك توك، إكس، انستقرام، يوتيوب، لينكدإن + تقويم محتوى |
| `saudi-seasonal-calendar` | رمضان، الأعياد، يوم التأسيس، يوم العلم، اليوم الوطني، الجمعة البيضاء، يوم الراتب |
| `saudi-influencer-marketing` | المؤثرون، رخصة موثوق، الإفصاح، البريف، القياس |
| `saudi-ad-compliance` | ترخيص التخفيضات، الضريبة، هيئة الغذاء والدواء، حماية البيانات، الذوق العام |
| `saudi-performance-ads` | الإعلانات الممولة، الميديا بلان، الميزانية بالريال، الاختبار والمؤشرات |
| `saudi-ecommerce-growth` | سلة/زد، الدفع (مدى، تابي، تمارا)، الشحن، تحسين التحويل |
| `saudi-local-seo` | السيو العربي، قوقل ماب، الكلمات بالعامية والفصحى |
| `saudi-whatsapp-crm` | واتساب للأعمال، SMS، تدفقات العملاء، خدمة العملاء |
| `saudi-brand-localization` | توطين البراند، الهوية البصرية، القيم الثقافية، RTL |

## طريقة الاستخدام
- **داخل هذا المستودع**: افتح Claude Code هنا وستعمل المهارات تلقائياً.
- **في كل مشاريعك**: انسخ المجلدات إلى `~/.claude/skills/`:
  ```bash
  cp -r .claude/skills/saudi-* ~/.claude/skills/
  ```

## ملاحظة
المهارات تحتوي قواعد عملية، لكن الأنظمة والتواريخ الهجرية وأرقام المنصات تتغير — Claude مُوجّه للتنبيه على ما يحتاج تحقق وعدم اختراع أرقام. هذه ليست استشارة قانونية.
