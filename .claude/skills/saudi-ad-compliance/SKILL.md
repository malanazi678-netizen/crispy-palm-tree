# امتثال الإعلان في السعودية

> هذه قائمة فحص عملية وليست استشارة قانونية. الأنظمة تتحدث باستمرار — اذكر للمستخدم أن يتحقق من الجهة المختصة لأي حالة حساسة.

## قائمة الفحص
### 1. اللغة والأسعار
- [ ] المحتوى بالعربية (مسموح إضافة لغة أخرى).
- [ ] الأسعار بالريال السعودي و**شاملة ضريبة القيمة المضافة 15%**، أو واضحة الإفصاح.
- [ ] الرسوم الإضافية (توصيل، خدمة) واضحة قبل الدفع.
- [ ] الفاتورة إلكترونية متوافقة مع متطلبات "فاتورة" من هيئة الزكاة والضريبة والجمارك (ZATCA).

### 2. التخفيضات والعروض (وزارة التجارة)
- [ ] **ترخيص التخفيض** صادر من وزارة التجارة قبل الإعلان عن أي تخفيض/تنزيلات، ورقمه ظاهر حيث يُطلب.
- [ ] السعر قبل وبعد حقيقي (السعر "قبل" كان معمولاً به فعلاً).
- [ ] مدة العرض محددة ومطابقة للترخيص.
- [ ] لا عبارات مضللة: "خصم يصل إلى 70%" يجب أن يكون منطبقاً فعلاً على منتجات حقيقية.
- [ ] المسابقات والسحوبات: تحتاج ترخيصاً من الجهة المختصة؛ اليانصيب/الشراء مقابل فرصة فوز قد يقع في المحظور.

### 3. التجارة الإلكترونية
- [ ] بيانات المتجر: السجل التجاري أو وثيقة العمل الحر/التوثيق عبر المركز السعودي للأعمال، العنوان، وسائل التواصل.
- [ ] سياسة الاسترجاع والاستبدال واضحة، وحق العدول عن الشراء حسب نظام التجارة الإلكترونية ولائحته.
- [ ] مدة التوصيل المعلنة واقعية.

### 4. الادعاءات
- [ ] **غذاء/دواء/تجميل/مكملات/أجهزة طبية**: أي ادعاء صحي أو علاجي يحتاج موافقة **هيئة الغذاء والدواء (SFDA)**، والمنتج مسجل.
- [ ] **مالية/استثمار/تمويل**: تخضع لرقابة البنك المركزي (ساما) أو هيئة السوق المالية — لا وعود بعوائد مضمونة.
- [ ] **عقار**: ضوابط الهيئة العامة للعقار (رخصة الإعلان العقاري للإعلانات العقارية).
- [ ] صيغ التفضيل ("الأول"، "الأفضل"، "رقم 1") مدعومة بدليل.
- [ ] المقارنة بالمنافسين: عادلة ولا تسيء.

### 5. المؤثرون والإعلام
- [ ] رخصة **موثوق** من GCAM للمؤثر المعلِن.
- [ ] الإفصاح الواضح أن المحتوى إعلان.
- [ ] إعلانات الطرق واللوحات: تصاريح البلدية/الأمانة.

### 6. البيانات الشخصية (نظام حماية البيانات الشخصية PDPL — سدايا)
- [ ] سياسة خصوصية واضحة بالعربية.
- [ ] موافقة صريحة للتسويق المباشر (إيميل/SMS/واتساب) مع خيار إلغاء الاشتراك سهل.
- [ ] عدم نقل البيانات خارج المملكة إلا وفق الضوابط.
- [ ] جمع الحد الأدنى من البيانات وتحديد الغرض.

### 7. الرسائل النصية (CST)
- [ ] اسم المرسل (Sender ID) مسجل عبر مزود معتمد.
- [ ] الرسائل الترويجية لمن وافق فقط، مع طريقة إلغاء الاشتراك، وفي الأوقات المسموحة.

### 8. القيم والذوق العام
- [ ] لا محتوى يخالف الثوابت الدينية أو لائحة الذوق العام.
- [ ] لا استخدام مسيء للعلم الوطني أو الشعار أو صور القيادة؛ العلم يحمل الشهادة ولا يوضع على ما يُرمى أو يُداس.
- [ ] لا كحول، مقامرة، محتوى جنسي، أو ترويج لمنتجات محظورة.
- [ ] تمثيل المرأة والأسرة باحترام.
- [ ] لا إساءة لأي منطقة، قبيلة، جنسية، أو دولة.

## صيغة المخرَج
جدول: البند، الحالة (✅ سليم / ⚠️ يحتاج تعديل / ❌ مخالف / ❓ يحتاج تحقق)، السبب، التعديل المقترح (قبل ← بعد)، الجهة المختصة. وأنهِ بتذكير أن هذا فحص مبدئي.
